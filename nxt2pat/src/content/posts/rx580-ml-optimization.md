# CPU-First Engineering: รันโมเดล Local AI บนฮาร์ดแวร์จริง

## 1. บริบทและความเป็นจริงของการพัฒนา AI

ในวงการปัญญาประดิษฐ์ยุคปัจจุบัน กระแสหลักมักมุ่งเน้นไปที่การใช้งานเซิร์ฟเวอร์การ์ดจอระดับท็อป (เช่น Nvidia H100 หรือ RTX 4090 ขนาดแรม 24GB+) และพึ่งพาไลบรารีขนาดมหึมาอย่าง PyTorch ขนาด 4–6GB

ทว่าในการประยุกต์ใช้งานจริงนอกห้องทดลอง ซอฟต์แวร์ส่วนใหญ่จำเป็นต้องรันบน **อุปกรณ์ปลายทาง (Edge Devices)** หรือคอมพิวเตอร์ทั่วไปของผู้ใช้งาน ซึ่งมักไม่มีการ์ดจอระดับเซิร์ฟเวอร์เหล่านั้น

บนเครื่องเวิร์กสเตชันหลักของผม ซึ่งใช้การ์ดจอ **AMD Radeon RX 590 GME (สถาปัตยกรรม Polaris 20 / gfx803)** แม้ซอฟต์แวร์ ROCm รุ่นใหม่ๆ ของค่ายจะเริ่มตัดการสนับสนุนสถาปัตยกรรมรุ่นเก่านี้ไปแล้ว แต่ข้อจำกัดนี้กลับกลายเป็น **ตัวผลักดันให้เกิดทักษะการปรับแต่งทางวิศวกรรมที่ลึกซึ้งยิ่งขึ้น**

## 2. เสาหลักการออกแบบระบบ AI แบบ "CPU-First"

```
┌────────────────────────────────────────────────────────┐
│                   LEAN ML PIPELINE                     │
├─────────────────────┬──────────────────┬───────────────┤
│    TRAINED MODEL    │  ONNX QUANTIZE   │ CPU INFERENCE │
│  PyTorch / Scikit   │  FP32 ──▶ INT8   │ C++ Runtime   │
│  Weight Pruning     │  75% Footprint   │ Sub-10ms Latency
└─────────────────────┴──────────────────┴───────────────┘
```

1. **เตรียม CPU Fallback เสมอ**: โค้ดที่ดีต้องไม่สันนิษฐานว่ามี CUDA อยู่ในระบบ หาก GPU ไม่พร้อมใช้งาน ไปป์ไลน์ต้องสลับมารันบน CPU ผ่านชุดคำสั่งเวกเตอร์ `AVX2 / FMA` ได้อย่างราบรื่นโดยไม่แคช
2. **Quantize โมเดลอย่างเด็ดขาด**: การแปลงขนาดของค่าน้ำหนัก (Weights) จาก FP32 (32-bit Floating Point) ลงมาเป็น INT8 หรือ INT4 ช่วยลดขนาดหน่วยความจำลงได้กว่า 70% และลดแบนด์วิดท์ในการดึงข้อมูลจาก RAM ลงอย่างมหาศาล
3. **ใช้ ONNX Runtime แทนเฟรมเวิร์กขนาดใหญ่**: แปลงโมเดลที่เทรนเสร็จแล้วให้อยู่ในฟอร์แมตกลาง ONNX แล้วรันผ่าน Runtime C++ น้ำหนักเบา ขจัดความจำเป็นในการติดตั้ง PyTorch ขนาดหลายกิกะไบต์

## 3. สรุปบทเรียน

เมื่อเราออกแบบซอฟต์แวร์ให้สามารถทำงานได้อย่างรวดเร็วและเสถียรบนฮาร์ดแวร์ที่มีทรัพยากรจำกัด เมื่อซอฟต์แวร์นั้นถูกนำไปติดตั้งบนเครื่องที่มีสเปกสูงขึ้น มันจะทำงานได้อย่างรวดเร็วและมีประสิทธิภาพเหนือกว่าระบบทั่วไปอย่างเห็นได้ชัด
