# Ashborne — เกมผจญภัยบรรยากาศ Pixel Art (Hamster Hub GameJamX)

## 1. จุดเริ่มต้นและความท้าทายใน Game Jam (The GameJam Sprint)

**Hamster Hub GameJamX** เป็นการแข่งขันพัฒนาเกมในระยะเวลาจำกัด ที่ท้าทายให้นักพัฒนาสร้างเกมที่สมบูรณ์ตั้งแต่การคิดคอนเซปต์, การเขียนโปรแกรม, การออกแบบภาพกราฟิก Pixel Art, ไปจนถึงการแต่งเสียงดนตรีประกอบ ภายในกรอบเวลาเพียงไม่กี่วัน

โปรเจกต์ **Ashborne** ได้รับการพัฒนาขึ้นโดยทีมงานในนาม **"Boy's Lham"** เพื่อเข้าร่วมการแข่งขัน โดยมีเป้าหมายสร้างเกมผจญภัยแนวพัซเซิล (Puzzle-Adventure) ที่เน้นการถ่ายทอดอารมณ์และบรรยากาศ (Atmospheric Environmental Storytelling) ในโลกที่ล่มสลายและปกคลุมด้วยเถ้าถ่าน

---

## 2. การออกแบบเกมเพลย์และปริศนา (Level Design & Mechanics)

```
┌─────────────────────────────────────────────────────────────────┐
│                     ASHBORNE GAME MECHANICS                     │
├─────────────────────┬───────────────────┬───────────────────────┤
│    LIGHT & SHADOW   │  PHYSICS PUZZLE   │  ATMOSPHERIC AUDIO    │
│  Torches & Embers   │  Weight Levers    │  Dynamic Ambient Cue  │
│  Safe Zones Defense │  Platform Timing  │  Environmental Lore   │
└─────────────────────┴───────────────────┴───────────────────────┘
```

1. **กลไกแสงไฟและความมืด (Light as a Sanctuary)**:
   - ผู้เล่นต้องเดินทางผ่านพื้นที่มืดที่เต็มไปด้วยอันตราย แหล่งกำเนิดแสง เช่น กองเถ้าถ่านและคบเพลิง คือพื้นที่ปลอดภัยเดียว
   - ผู้เล่นต้องบริหารจัดการเชื้อเพลิงเพื่อจุดไฟเปิดทางไปยังพื้นที่ถัดไป
2. **ปริศนาเชิงฟิสิกส์และจังหวะเวลา (Physics-Driven Puzzles)**:
   - การเลื่อนกล่องถ่วงน้ำหนักเพื่อเปิดประตูกล
   - การจับจังหวะการเคลื่อนที่ของแท่นลอยน้ำและการหลบหลีกกับดักหนาม
3. **การเล่าเรื่องแบบเงียบงัน (Show, Don't Tell)**:
   - สื่อสารเรื่องราวผ่านฉากหลัง ซากปรักหักพัง และเสียงบรรยากาศ (Ambient Soundscape) โดยไม่มีบทสนทนายาวเหยียด เพื่อให้ผู้เล่นได้ตีความโลกของเกมด้วยตนเอง

---

## 3. การทำงานเป็นทีมและการบริหารขอบเขตงาน (Scope Management)

สิ่งที่ท้าทายที่สุดในการแข่งขัน Game Jam คือ **"การคุม Scope ไม่ให้บานปลาย"**:
- **การแบ่งหน้าที่ชัดเจน**: วางผังงานอย่างรัดกุมระหว่างฝ่ายโปรแกรมมิ่ง ออกแบบด่าน และงานศิลป์ Pixel Art
- **Rapid Prototyping**: ทำบล็อกเทสติ้ง (Blockout Mechanics) ด้วยรูปทรงสี่เหลี่ยมธรรมดาก่อน เพื่อทดสอบว่ากลไกการกระโดดและปริศนาสนุกจริง จากนั้นจึงนำภาพวาด Pixel Art มาสวมทับ
- ส่งมอบผลงานเวอร์ชันสมบูรณ์ได้ทันเวลา และเปิดให้ดาวน์โหลดเล่นบน **Itch.io**

---

## 4. ผลลัพธ์และประสบการณ์ที่ได้รับ

- ได้รับฟีดแบ็กที่ดีจากเพื่อนๆ ผู้เข้าร่วมการแข่งขันและคอมมูนิตี้ผู้เล่นบน Itch.io ชื่นชมในบรรยากาศและงานศิลป์ของเกม
- ฝึกฝนทักษะการทำงานร่วมกับผู้อื่นภายใต้ความกดดันของเวลา (Time Crunch) การตัดสินใจตัดฟีเจอร์ที่ไม่จำเป็นออก และการส่งมอบซอฟต์แวร์ที่ใช้งานได้จริงตรงตามกำหนดเวลา
