# Arduino UNO Robotics Challenge — Coding Thailand 2026 (รองชนะเลิศอันดับ 2 ระดับชาติ)

## 1. บริบทและภารกิจการแข่งขัน (Competition Context & Objectives)

โครงการ **Coding Thailand 2026** จัดขึ้นโดย **สำนักงานส่งเสริมเศรษฐกิจดิจิทัล (depa)** ร่วมกับ **องค์การพิพิธภัณฑ์วิทยาศาสตร์แห่งชาติ (อพวช.)** เพื่อส่งเสริมทักษะด้านโค้ดดิ้ง วิทยาการคำนวณ และระบบสมองกลฝังตัวสำหรับเยาวชนทั่วประเทศ

ในการแข่งขัน **Arduino Robotics Challenge** ผู้เข้าแข่งขันจะต้อง:
1. ออกแบบ ประกอบ และเขียนโปรแกรมควบคุมหุ่นยนต์อัตโนมัติด้วยบอร์ด Arduino
2. วิ่งตรวจจับและเคลื่อนที่ตามเส้น (Line Tracking) บนสนามแข่งที่มีความคดเคี้ยว ทางแยก ทางตัด และจุดกลับตัว
3. สแกนตรวจจับสิ่งกีดขวางฉุกเฉินด้วยเซนเซอร์อัลตราโซนิก เพื่อหยุดหรือเบี่ยงหลบเข้าสู่ช่องทางสำรอง
4. ทำภารกิจให้สำเร็จครบถ้วนภายในเวลาที่กำหนด โดยได้รับโทษเวลา (Penalty) น้อยที่สุด

ผลการแข่งขัน: สามารถประมวลผลเซนเซอร์ได้อย่างแม่นยำ คว้ารางวัล **รองชนะเลิศอันดับ 2 ระดับชาติ (2nd Runner-Up)**

## 2. โครงสร้างฮาร์ดแวร์และการเชื่อมต่อระบบ (Hardware & Circuitry)

```
┌─────────────────────────────────────────────────────────────────┐
│                    ARDUINO ROBOT ARCHITECTURE                   │
├─────────────────────┬───────────────────┬───────────────────────┤
│   SENSOR INPUTS     │    ARDUINO CORE   │    OUTPUT ACTUATORS   │
│  Multi-IR Line Array│  Finite State     │  L298N/MOSFET Driver  │
│  Ultrasonic Echo    │  Adaptive Threshold│ Dual DC Geared Wheels │
└─────────────────────┴───────────────────┴───────────────────────┘
```

1. **หน่วยประมวลผลกลาง**: บอร์ดไมโครคอนโทรลเลอร์ Arduino รันเฟิร์มแวร์ภาษา C++ แบบ Bare-Metal วงรอบการทำงานเร็วระดับมิลลิวินาที
2. **ระบบตรวจจับเส้น (Infrared Line Tracking Array)**:
   - ติดตั้งเซนเซอร์อินฟราเรดสะท้อนแสง (IR Reflectance Sensors) จำนวน 5 จุดเรียงหน้ากระดานด้านใต้ท้องหุ่นยนต์
   - ตรวจจับความแตกต่างของค่าสะท้อนแสงระหว่างพื้นสีขาวและเส้นสีดำ
3. **ระบบวัดระยะสิ่งกีดขวาง (Ultrasonic Ranging)**:
   - โมดูล HC-SR04 ติดตั้งด้านหน้า วัดระยะสะท้อนคลื่นเสียงความถี่สูง ตรวจจับวัตถุขวางหน้าในระยะ 2–20 ซม.
4. **ระบบขับเคลื่อน (Drive Subsystem)**:
   - มอเตอร์กระแสตรงพร้อมชุดทดเฟืองโลหะ (High-Torque DC Gear Motors)
   - วงจรขับมอเตอร์ H-Bridge รับสัญญาณ PWM จาก Arduino เพื่อควบคุมความเร็วอิสระซ้าย-ขวา

## 3. อัลกอริทึมและการแก้ปัญหาเชิงเทคนิค (Algorithms & Solutions)

### 3.1 การปรับจูนค่าเกณฑ์แสงแบบอัตโนมัติ (Dynamic Threshold Calibration)
- **ปัญหา**: สภาพแสงในห้องแข่งขัน (หลอดไฟนีออน / แสงแดดส่องผ่านหน้าต่าง) มักไม่เท่ากับห้องซ้อมที่โรงเรียน ทำให้ค่าอนาล็อกที่เซนเซอร์อ่านได้เพี้ยน หุ่นยนต์หลุดเส้น
- **การแก้ปัญหา**: 
  - เขียนฟังก์ชัน Calibration ในช่วงเริ่มต้น (Boot Sequence)
  - ให้หุ่นยนต์หมุนตัวกวาดเซนเซอร์ซ้าย-ขวา 1 วินาที เพื่อบันทึกค่าแสงสูงสุด (Max Reflectance) และต่ำสุด (Min Reflectance) ของสนามจริง
  - คำนวณค่าเกณฑ์กึ่งกลาง (Threshold) แบบไดนามิก ทำให้หุ่นยนต์ทำงานเสถียรในทุกสภาพแสง

### 3.2 Smooth Proportional Line Following
- แทนที่จะใช้การเลี้ยวแบบหักเลี้ยวทันที (Bang-Bang Control) ซึ่งทำให้หุ่นยนต์ส่ายและเสียความเร็ว
- ใช้อัลกอริทึม Proportional (P-Controller) คำนวณความเบี่ยงเบนของจุดกึ่งกลางเส้น แล้วปรับเพิ่ม-ลดความเร็วล้อซ้ายขวาอย่างนุ่มนวล ส่งผลให้หุ่นยนต์เข้าโค้งแคบได้ด้วยความเร็วสูงโดยไม่หลุดเส้น
