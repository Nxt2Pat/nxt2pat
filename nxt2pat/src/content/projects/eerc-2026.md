# หุ่นยนต์กู้ภัยอัตโนมัติ EERC 2026 (รางวัลรองชนะเลิศอันดับ 2 KMITL EXPO)

## 1. ที่มาและภารกิจการแข่งขัน (Competition Context & Mission)

การแข่งขัน **EERC 2026 (Engineering & Educational Robotics Challenge 2026)** จัดขึ้นภายใต้งาน **KMITL EXPO** ณ สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง (สจล.) เป็นเวทีประลองทักษะการออกแบบและสร้างหุ่นยนต์อัตโนมัติระดับเยาวชนชั้นนำของประเทศ

ภารกิจของการแข่งขันคือการสร้างหุ่นยนต์กู้ภัยอัตโนมัติ (Autonomous Rescue Robot) ที่ต้อง:
1. เคลื่อนที่ผ่านเส้นทางจำลองเขตภัยพิบัติที่ซับซ้อน ประกอบด้วย ทางลาดชัน (Inclined Ramps), ผิวขรุขระ, ทางโค้งหักศอก, และอุโมงค์แคบ
2. ตรวจจับและหลบหลีกสิ่งกีดขวางที่จัดวางแบบสุ่มโดยไม่ให้สัมผัสหรือชนขอบสนาม
3. สำรวจจุดเป้าหมายและนำส่งวัตถุช่วยเหลือผู้ประสบภัยไปยังจุดปลอดภัยโดยอัตโนมัติ 100% ปราศจากการควบคุมด้วยมือมนุษย์

ผลการแข่งขัน: หุ่นยนต์สามารถฝ่าด่านอุปสรรคและทำภารกิจได้อย่างแม่นยำ คว้ารางวัล **รองชนะเลิศอันดับ 2 (2nd Runner-Up)** มาครองได้สำเร็จ

---

## 2. โครงสร้างฮาร์ดแวร์และวงจรไฟฟ้า (Hardware & Electromechanical Design)

```
┌─────────────────────────────────────────────────────────────────┐
│                    EERC 2026 ROBOT ARCHITECTURE                 │
├─────────────────────┬───────────────────┬───────────────────────┤
│   SENSING ARRAY     │  MICROCONTROLLER  │   ACTUATION & DRIVE   │
│  Ultrasonic Ping    │  Real-time PID    │  Dual DC Gear Motors  │
│  Optical Encoders   │  Vector Compute   │  H-Bridge PWM Driver  │
└─────────────────────┴───────────────────┴───────────────────────┘
```

1. **โครงสร้างทางกล (Chassis & Drivetrain)**:
   - โครงสร้างอะลูมิเนียมคอมโพสิตน้ำหนักเบาและแข็งแรงสูง รองรับแรงกระแทกและแรงสั่นสะเทือนจากพื้นสนาม
   - ระบบขับเคลื่อนแบบ **Differential Drive** ใช้ล้อขับเคลื่อน 2 ล้อพร้อมยางซิลิโคน High-Traction เสริมล้อประคอง (Caster Wheel) แบบตลับลูกปืนแรงเสียดทานต่ำ
2. **ระบบขับเคลื่อนมอเตอร์ (Actuators & Power)**:
   - มอเตอร์กระแสตรงพร้อมชุดเกียร์โลหะ (Metal Geared DC Motors) ให้แรงบิดสูงเพียงพอต่อการไต่ทางชัน
   - ควบคุมความเร็วและทิศทางผ่านวงจรขับมอเตอร์ H-Bridge (MOSFET-based) ด้วยสัญญาณความถี่ PWM 20 kHz
   - จ่ายไฟด้วยแบตเตอรี่ Lithium-Polymer (LiPo 3S 11.1V) พร้อมวงจร Buck Converter แปลงแรงดันไฟเลี้ยงเซนเซอร์ 5V นิ่งสนิท ป้องกันสัญญาณรบกวนจากขดลวดมอเตอร์
3. **ระบบเซนเซอร์ตรวจจับรอบทิศทาง (Sensor Array)**:
   - **Optical Quadrature Rotary Encoders** ติดตั้งที่เพลามอเตอร์ทั้งสองข้าง วัดรอบการหมุนระดับความละเอียดสูง
   - **Ultrasonic Distance Sensors** ติดตั้งด้านหน้าและด้านข้าง วัดระยะห่างจากสิ่งกีดขวางด้วยคลื่นความถี่ 40 kHz
   - **Infrared Proximity Array** ด้านหน้าล่าง สำหรับตรวจจับขอบเขตและหลุมสนาม

## 3. ความท้าทายหลักทางวิศวกรรมและการแก้ปัญหา (Core Engineering Breakthroughs)

### 3.1 ปัญหาล้อเอียงและแรงเสียดทานไม่สมดุล (Frictional Asymmetry)
- **ปัญหา**: ในสนามจริง มอเตอร์สองตัวแม้จะจ่ายแรงดันไฟฟ้าเท่ากัน แต่ด้วยความคลาดเคลื่อนของเกียร์และแรงเสียดทานพื้นสนามที่ไม่เท่ากัน จะทำให้หุ่นยนต์วิ่งเป๋ไม่ตรงทาง เมื่อเดินทางเป็นระยะไกล ความคลาดเคลื่อนจะสะสมจนหุ่นยนต์ชนขอบสนาม
- **การแก้ปัญหา**: 
  - ยกเลิกการสั่งงานมอเตอร์แบบ Open-Loop (ควบคุมด้วยแรงดันคงที่)
  - พัฒนาระบบ **Closed-Loop Feedback Control ด้วยอัลกอริทึม PID (Proportional-Integral-Derivative)**
  - อ่านสัญญาณ Pulse จาก Encoder ทั้งสองล้อทุกๆ 10 มิลลิวินาที คำนวณความเร็วเชิงมุมเปรียบเทียบระหว่างล้อซ้ายและล้อขวา
  - ชดเชยกำลังขับของมอเตอร์แต่ละข้างแบบเรียลไทม์ ทำให้หุ่นยนต์สามารถวิ่งเป็นเส้นตรงได้อย่างสมบูรณ์แบบแม้พื้นสนามจะลื่นหรือเอียง

### 3.2 การนำทางผ่านสิ่งกีดขวางด้วย State Machine
- ควบคุมลำดับการตัดสินใจของหุ่นยนต์ด้วย Finite State Machine (FSM):
  - `STATE_CRUISE`: วิ่งตรงด้วยความเร็วสูงสุดพร้อมรักษาระยะห่างจากผนัง
  - `STATE_OBSTACLE_AVOID`: เมื่อเซนเซอร์ด้านหน้าตรวจพบสิ่งกีดขวางในระยะ 15 ซม. หุ่นยนต์จะลดความเร็วลงอย่างนุ่มนวล หมุนตัวสแกนหาเส้นทางว่าง แล้วเบี่ยงทิศทางหลบหลีก
  - `STATE_RAMP_ASCENT`: เมื่อเซนเซอร์วัดมุมเอียงตรวจพบการไต่ทางชัน อัลกอริทึมจะเพิ่มค่าพารามิเตอร์ Integral ใน PID ชั่วคราวเพื่ออัดแรงบิดเพิ่ม ป้องกันหุ่นยนต์ไหลย้อนกลับ

## 4. ผลลัพธ์และบทเรียนสำคัญ

- ได้รับรางวัล **รองชนะเลิศอันดับ 2 (2nd Runner-Up)** จากผู้เข้าแข่งขันทั่วประเทศ
- ตอกย้ำความเข้าใจว่า **ฮาร์ดแวร์ที่ดีต้องการซอฟต์แวร์ควบคุมที่ชาญฉลาด** ปัญหาทางกลศาสตร์หลายอย่างไม่จำเป็นต้องแก้ด้วยการเปลี่ยนชิ้นส่วนราคาแพง แต่สามารถแก้ไขได้อย่างแม่นยำด้วยการเขียนอัลกอริทึมชดเชยที่ถูกต้อง
