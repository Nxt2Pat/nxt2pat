# Micro-Invasion — เกมชีววิทยาแนว Roguelike เอาชีวิตรอดในระบบภูมิคุ้มกัน

## 1. แรงบันดาลใจและแนวคิดของเกม (Inspiration & Concept)

โดยทั่วไป เกมแนวเอาชีวิตรอดจากฝูงศัตรู (Survivor / Horde Survival) มักให้ผู้เล่นรับบทเป็นอัศวินหรือยานอวกาศ แต่ **Micro-Invasion** นำแนวคิดมาจากความรู้ในบทเรียนวิทยาศาสตร์และชีววิทยาเรื่อง **"ระบบภูมิคุ้มกันร่างกายมนุษย์ (The Human Immune System)"**:

ผู้เล่นจะได้รับบทบาทเป็น **"จุลินทรีย์กลายพันธุ์ (Mutating Microorganism)"** ที่หลุดเข้ามาในกระแสเลือด หน้าที่ของผู้เล่นคือ:
1. เก็บเกี่ยวสารอาหาร (Glucose / Amino Acids) เพื่อสะสมค่าพลังงาน DNA
2. นำสารอาหารไปกลายพันธุ์อวัยวะและคุณสมบัติทางกายภาพของเซลล์
3. หลบหลีกและต่อสู้กับเซลล์เม็ดเลือดขาวชนิดต่างๆ ที่ถูกส่งมากำจัด เช่น เม็ดเลือดขาว Neutrophil ที่เคลื่อนที่รวดเร็ว, Macrophage ที่คอยกลืนกินสิ่งแปลกปลอม, และ Antibodies ที่คอยตรึงการเคลื่อนไหว

เกมได้รับการเผยแพร่บนแพลตฟอร์มเกมอินดี้ **Itch.io** และเปิดให้ผู้เล่นดาวน์โหลดไปเล่นได้ฟรี

## 2. กลไกการเล่นและสายวิวัฒนาการ (Gameplay Mechanics & Evolution Trees)

```
┌─────────────────────────────────────────────────────────────────┐
│                    MICRO-INVASION GAME LOOP                     │
├─────────────────────┬───────────────────┬───────────────────────┤
│   SURVIVAL EVASION  │  NUTRIENT HARVEST │   MUTATION TREE       │
│  Dodge White Cells  │  Phagocytosis     │  Flagella Speed       │
│  Flank Macrophages  │  Absorb Nutrients │  Toxin Spikes & Wall  │
└─────────────────────┴───────────────────┴───────────────────────┘
```

- **กลไกการเคลื่อนที่แบบจุลทัศน์ (Microscopic Viscosity)**: น้ำในกระแสเลือดมีความหนืด (Low Reynolds Number Dynamics) การเคลื่อนที่จึงมีแรงเฉื่อยจำเพาะ เซลล์ไม่ได้เคลื่อนที่เหมือนยานอวกาศในสุญญากาศ
- **สายการกลายพันธุ์ของ DNA**:
  - *Flagella Extension*: เพิ่มหางแฟลกเจลลาเพื่อเร่งความเร็วในการว่ายหนี
  - *Peptidoglycan Cell Wall*: เสริมผนังเซลล์ให้หนาขึ้น เพิ่มพลังชีวิตและทนทานต่อแรงย่อยของเอนไซม์
  - *Bacterial Toxin Spikes*: สร้างหนามพิษรอบตัว เมื่อเซลล์เม็ดเลือดขาวพุ่งชนจะได้รับความเสียหายสะท้อนกลับ

## 3. ความท้าทายทางวิศวกรรมและการแก้ปัญหา (Technical Optimization)

เนื่องจากภาษา **Python** เป็นภาษาประเภท Interpreted ที่ไม่ได้เร็วเท่ากับ C++ หรือ Rust และการใช้ไลบรารี **Pygame** ในการเรนเดอร์วัตถุจำนวนมากมักประสบปัญหาเฟรมเรตร่วงหล่นเมื่อมีเซลล์บนหน้าจอหลายร้อยตัว:

### 3.1 การประมวลผลการชนด้วย Spatial Hash Grid
- **ปัญหา**: หากใช้วิธีเปรียบเทียบการชนแบบ Brute-Force ($O(N^2)$) ระหว่างเซลล์ 500 ตัว จะต้องคำนวณระยะห่างถึง $500 \times 500 = 250,000$ ครั้งในทุกๆ เฟรม ซึ่งทำให้เกมกระตุกรุนแรง (< 15 FPS)
- **การแก้ปัญหา**: 
  - ออกแบบโครงสร้างข้อมูล **Spatial Hash Grid** แบ่งแผนที่ออกเป็นช่องตารางขนาดคงที่
  - วัตถุจะลงทะเบียนพิกัดเฉพาะในช่องตารางที่ตนเองครอบครอง
  - การตรวจสอบการชนจะทำเฉพาะกับวัตถุที่อยู่ในช่องตารางเดียวกันหรือช่องข้างเคียงเท่านั้น ลดความซับซ้อนของการคำนวณลงเหลือเกือบเป็นเส้นตรง $O(N)$
  - ส่งผลให้เกมสามารถรันเซลล์ได้มากกว่า 500 เซลล์พร้อมกันที่ **60 FPS** เต็ม บนคอมพิวเตอร์สเปกทั่วไปได้อย่างลื่นไหล

### 3.2 Fixed-Timestep Physics Loop
- แยกตรรกะการคำนวณฟิสิกส์ (Physics Step 60 Hz) ออกจากการเรนเดอร์ภาพ (Render Step) ป้องกันไม่ให้ความเร็วของเกมเพี้ยนเมื่อเกิดอาการสะดุดของหน้าจอ
