# TugOfWarMath — เว็บเกมชักเย่อตอบปัญหาคณิตศาสตร์เรียลไทม์ (ค่ายคณิต ม.6 สู่ ม.1)

## 1. จุดเริ่มต้นและเหตุผลในการพัฒนา (Origin & Purpose)

โปรเจกต์นี้ **ไม่ใช่โครงงานส่งประกวดทางวิชาการ** แต่เป็นผลงานที่เกิดขึ้นจากโจทย์และการใช้งานจริงในชีวิตโรงเรียน:

ในฐานะนักเรียนชั้น ม.6 โรงเรียนเทพศิรินทร์ สมุทรปราการ ที่ได้รับมอบหมายให้เป็นผู้จัดกิจกรรม **"ค่ายคณิตศาสตร์สำหรับน้อง ม.1"** ปัญหาใหญ่ที่มักพบในกิจกรรมค่ายวิชาการแบบเดิมๆ คือ:
1. **บรรยากาศการเรียนรู้น่าเบื่อ**: การทำข้อสอบบนกระดาษหรือการตอบคำถามทั่วไปทำให้น้องๆ ขาดความกระตือรือร้นและรู้สึกกลัววิชาคณิตศาสตร์
2. **แพลตฟอร์มสำเร็จรูป (เช่น Kahoot / Quizizz) มีข้อจำกัด**: แม้จะสนุก แต่เป็นเพียงการสะสมคะแนนรายบุคคล ไม่สร้างความรู้สึกร่วมของการทำงานเป็นทีม (Team Collaboration) และบางครั้งมีข้อจำกัดเรื่องโฆษณา หรือจำนวนผู้เล่นฟรีในห้อง
3. **ปัญหาอินเทอร์เน็ตในโรงเรียน**: เน็ตเวิร์กของโรงเรียนบางห้องมีสัญญาณช้า การให้น้องทุกคนเชื่อมต่อไปยังเซิร์ฟเวอร์ต่างประเทศพร้อมกันมักทำให้หน้าเว็บค้าง

ผมจึงตัดสินใจ **เขียนเว็บแอปพลิเคชันขึ้นมาใหม่ด้วยตนเอง** เพื่อสร้างประสบการณ์การเรียนรู้รูปแบบใหม่ที่เปลี่ยนการคิดเลขเร็วให้กลายเป็นการ **"แข่งขันชักเย่อระหว่างทีมแบบเรียลไทม์"**

## 2. กติกาและประสบการณ์ของผู้เล่น (Game Design & Player Experience)

```
┌─────────────────────────────────────────────────────────────────┐
│                    TUGOFWARMATH GAMEPLAY                        │
├─────────────────────┬───────────────────┬───────────────────────┤
│    TEAM A (RED)     │   MAIN PROJECTOR  │    TEAM B (BLUE)      │
│  Mobile Browser Web │ Real-Time Canvas  │  Mobile Browser Web   │
│  Solve Math Prompts │ Rope Physics Pull │  Solve Math Prompts   │
└─────────────────────┴───────────────────┴───────────────────────┘
```

1. **การเข้าร่วมเกมที่ง่ายดาย**: 
   - บนหน้าจอโปรเจกเตอร์หลักกลางห้องจะแสดง QR Code และรหัสห้อง (Room Code)
   - น้องๆ ม.1 เพียงใช้สมาร์ตโฟนสแกน QR Code เพื่อเปิดเว็บแอปพลิเคชัน ใส่ชื่อ และเลือกว่าจะอยู่ **"ทีมสีแดง"** หรือ **"ทีมสีน้ำเงิน"** โดยไม่ต้องดาวน์โหลดแอปหรือสมัครบัญชีให้ยุ่งยาก
2. **กลไกชักเย่อเรียลไทม์ (Tug-of-War Vector Dynamics)**:
   - สมาชิกแต่ละคนจะได้โจทย์คิดเลขเร็วบนมือถือตนเอง (สุ่มตามระดับความยากที่พี่ ม.6 เตรียมไว้)
   - เมื่อใครในทีมตอบถูก จะสร้างแรงดึง (Tug Force Vector) ให้เชือกชักเย่อบนจอโปรเจกเตอร์หลักขยับเข้าหาฝั่งทีมของตนเอง
   - หากตอบผิด เชือกจะหยุดนิ่งหรือถูกฝั่งตรงข้ามดึงเปรียบเทียบทันที
   - เมื่อหมดเวลา หรือฝั่งใดสามารถดึงเชือกข้ามเส้นชัยได้ก่อน ทีมนั้นจะเป็นฝ่ายชนะ

## 3. โครงสร้างสถาปัตยกรรมระบบ (System Architecture)

ระบบถูกออกแบบให้ทำงานแบบ **Local-First & Ultra-Low Latency** เพื่อรับประกันว่าการเล่นเกมจะลื่นไหลแม้ไม่มีอินเทอร์เน็ตภายนอก:

### 3.1 การสื่อสารสองทางผ่าน WebSocket (Bidirectional Real-Time Sync)
- เซิร์ฟเวอร์พัฒนาด้วย Node.js และ WebSocket (ws / Socket.io) ทำหน้าที่กระจายสถานะเกม (Game State Broadcasting)
- สตรีมตำแหน่งของจุดกึ่งกลางเชือก (Rope X-Coordinate), แรงตึงสะสม, และประวัติการตอบคำถามของนักเรียนกว่า 60+ เครื่องพร้อมกัน ด้วยค่าความหน่วงต่ำกว่า **30 มิลลิวินาที**

### 3.2 การเรนเดอร์ภาพกราฟิกด้วย HTML5 Canvas API
- หน้าจอโปรเจกเตอร์หลักใช้ HTML5 Canvas เรนเดอร์การเคลื่อนที่ของเชือกชักเย่อ, ธงกึ่งกลาง, และการสั่นไหวของเส้นเชือกตามสมการฟิสิกส์สปริง (Spring Damping Physics) ให้ความรู้สึกกระชับและมีชีวิตชีวา

### 3.3 การรองรับ Local Area Network (LAN Fallback)
- สามารถรันเซิร์ฟเวอร์บนเครื่องโน้ตบุ๊กของพี่ ม.6 และปล่อย WiFi Hotspot ในห้องเรียน
- น้องๆ เชื่อมต่อผ่าน Local IP (เช่น `http://192.168.1.100:3000`) เล่นเกมได้ทันที 100% แม้โรงเรียนจะถูกตัดสัญญาณอินเทอร์เน็ตภายนอก

## 4. ความท้าทายหน้างานและการปรับปรุง (Field Optimization)

### การป้องกันการแย่งสแปมคำตอบ (Race Conditions & Anti-Cheat)
- **ปัญหา**: ในตอนทดสอบช่วงแรก สมาชิกบางคนพยายามกดสุ่มช้อยส์คำตอบรัวๆ เพื่อหวังเพิ่มแรงดึง
- **การแก้ปัญหา**: นำระบบ Penalty Cooldown มาใช้ หากตอบผิดจะติดดีเลย์ 3 วินาทีไม่สามารถตอบข้อต่อไปได้ทันที ส่งผลให้น้องๆ ต้องตั้งใจคิดเลขจริง ไม่สามารถกดเดาได้

### การจัดการโหลดผู้เล่นจำนวนมากพร้อมกัน
- ใช้โครงสร้างข้อมูลแบบ In-Memory State บน Node.js หลีกเลี่ยงการอ่าน/เขียนฐานข้อมูลในลูปการคำนวณ ทำให้เครื่องเซิร์ฟเวอร์โน้ตบุ๊กธรรมดาสามารถรองรับนักเรียนได้ทั้งห้องพร้อมกันโดย CPU ใช้งานไม่ถึง 10%

## 5. ผลลัพธ์และคุณค่าที่ได้รับ

- กิจกรรมค่ายคณิตศาสตร์ประสบความสำเร็จอย่างงดงาม น้องๆ ม.1 มีส่วนร่วมอย่างกระตือรือร้น ส่งเสียงเชียร์ให้เพื่อนในทีม และแย่งกันคิดเลขอย่างสนุกสนาน
- พิสูจน์ให้เห็นว่า **การเขียนโปรแกรมไม่ใช่เพียงการทำงานวิจัยเชิงทฤษฎี** แต่เป็นเครื่องมืออันทรงพลังในการแก้ปัญหาเฉพาะหน้า สร้างความสุข และสร้างประสบการณ์การเรียนรู้ที่มีความหมายให้กับผู้อื่น
